# 🧮 Calculadora Interativa

Uma calculadora interativa desenvolvida com **HTML5, CSS3 e JavaScript**, com foco em praticidade, experiência do usuário e responsividade.

O projeto conta com uma interface moderna e funcionalidades que vão além das operações matemáticas tradicionais, incluindo reconhecimento de voz, histórico de cálculos e alternância entre temas claro e escuro.

## 🚀 Demonstração

🔗 **Acesse o projeto:** https://calculadora-six-virid.vercel.app/

## ✨ Funcionalidades

- ➕ Operações matemáticas básicas: adição, subtração, multiplicação e divisão.
- 📊 Cálculo de porcentagem.
- ➖ Alternância de sinal positivo e negativo.
- 🎙️ Reconhecimento de voz em português (pt-BR).
- 🕘 Histórico de cálculos com armazenamento no navegador.
- 🌙 Alternância entre tema claro e escuro.
- ⌨️ Suporte a operações pelo teclado.
- 📱 Interface responsiva para dispositivos móveis e desktops.
- 💾 Persistência de preferências e histórico utilizando LocalStorage.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, layouts responsivos, animações e temas.
- **JavaScript:** lógica matemática, manipulação do DOM, eventos e funcionalidades interativas.
- **Web Speech API:** reconhecimento de comandos de voz.
- **LocalStorage:** armazenamento local do histórico e das preferências do usuário.

## 📂 Estrutura do projeto

```text
calculadora/
│
├── index.html
├── calculadora.js
└── README.md
```

O arquivo JavaScript contém a lógica da calculadora e também injeta dinamicamente a estrutura HTML e os estilos CSS na página.

## 💻 Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/Renato-Rhuan/calculadora.git
```

2. Entre na pasta:

```bash
cd calculadora
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um ambiente de build.

**Observação:** para utilizar o reconhecimento de voz, é necessário um navegador compatível com a Web Speech API e a permissão de acesso ao microfone.
